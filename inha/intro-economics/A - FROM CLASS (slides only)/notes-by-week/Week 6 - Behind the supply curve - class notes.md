## 1. Big picture

- A **production function** links the quantity of inputs to the quantity of output. In the **short run** at least one input is fixed (George and Martha's land), so output depends on the variable input (labor). The **total product curve** shows this [S3–S5].
- Production shows **diminishing returns**: each extra worker adds less wheat (MPL = 19, 17, 15 … 5). In the professor's notation, Q = f(L) with f′(L) > 0 but f″(L) < 0 [S5, S7, S8]. More of the fixed input (20 acres instead of 10) shifts both TP and MPL up [S9].
- Costs: there are explicit and implicit costs [S10]. **TC = FC + VC**, where FC is the cost of the fixed input and VC is the cost of the variable input. Diminishing returns make the total cost curve get steeper [S11–S14].
- The two key concepts are **marginal cost**, MC = ΔTC/ΔQ, and **average cost**: ATC = TC/Q, AFC = FC/Q, AVC = VC/Q. At Ben's Boots, MC rises $12, $36 … $228, so the MC curve slopes upward [S15–S22].
- ATC is **U-shaped**. At low output the spreading effect (falling AFC) wins; at high output the diminishing returns effect (rising AVC) wins. The bottom of the U is the **minimum-cost output**: 3 pairs at Ben's Boots, where ATC = $72 and MC crosses ATC [S21–S25].
- ⭐ The professor's proof: dATC/dQ = (1/Q)(MC − ATC), so ATC is at its minimum where MC = ATC. When MC < ATC, ATC falls; when MC > ATC, ATC rises. The same holds for AVC. In his words, "For the average to be bigger, the new comer has to be greater than the average" [S27–S28].
- Short run vs long run: a firm can trade higher fixed cost for lower variable cost. Low FC gives lower ATC at low output, and high FC gives lower ATC at high output [S29]. The **LRATC** curve shows ATC when fixed cost has been chosen for each output level. Falling LRATC means economies of scale, rising LRATC means diseconomies of scale, and flat LRATC means constant returns to scale [S30–S32].

### [S8] Diminishing returns to an input, with the professor's calculus
- ⭐ PROFESSOR'S OWN SLIDE — high exam priority. The layout is the standard template, but the equation lines are the professor's addition.
- "There are **diminishing returns to an input** when an increase in the quantity of that input, holding the levels of all other inputs fixed, leads to a decline in the marginal product of that input."
- "Diminishing returns = Marginal product is decreasing"
- "When f is the production function which depends on the input labor L,"
  - Total production: **Q = f(L)** "is a increasing function on L"
  - Marginal production: **Q′ = f′(L) > 0, but Q″ = f″(L) < 0**
- **Meaning, step by step:**
  - Q′ = f′(L) is marginal production, which is the slope of TP. Because it is > 0, each extra worker still adds output, so TP rises.
  - Q″ = f″(L) < 0 means that marginal production is itself falling as L rises. This is the slide's "Marginal product is decreasing", i.e. diminishing returns.
  - Numbers from [S5]: MPL = 19, 17, 15, 13, 11, 9, 7, 5. All are positive (f′ > 0) and each is smaller than the one before (f″ < 0).
- This describes the rising part of TP. [S7] shows that once MP reaches 0 or turns negative, TP stops rising or falls.
- ⚠️ Possible slide typo: "is a increasing function on L" (correct: "is an increasing function of L").

### [S22] U-shaped ATC curve; AFC; AVC — formula (7-5)
- "A **U-shaped average total cost curve** falls at low levels of output, then rises at higher levels."
- "**Average fixed cost** is the fixed cost per unit of output."
- "**Average variable cost** is the variable cost per unit of output."
- **(7-5)** AFC = Fixed cost ÷ Quantity of output = **FC/Q**

### [S23] Spreading effect vs diminishing returns effect
- "Increasing output has two opposing effects on average total cost—the "spreading effect" and the "diminishing returns effect":"
  - "The **spreading effect**: the larger the output, the more production that can "share" the fixed cost, and therefore the lower the average fixed cost."
  - "The **diminishing returns effect**: the more output produced, the more variable input it requires to produce additional units, and therefore the higher the average variable cost."
- **The tug-of-war in Table 7-2's numbers (computed):**

| Move | Change in AFC (spreading) | Change in AVC (diminishing returns) | Change in ATC | Who wins |
|---|---|---|---|---|
| 1 → 2 pairs | 108 → 54 (−54) | 12 → 24 (+12) | 120 → 78 (−42) | spreading |
| 2 → 3 pairs | 54 → 36 (−18) | 24 → 36 (+12) | 78 → 72 (−6) | spreading |
| 3 → 4 pairs | 36 → 27 (−9) | 36 → 48 (+12) | 72 → 75 (+3) | diminishing returns |
| 4 → 5 pairs | 27 → 21.60 (−5.40) | 48 → 60 (+12) | 75 → 81.60 (+6.60) | diminishing returns |

### [S27] Relations among TC, MC, ATC, AVC — the proof
- ⭐ PROFESSOR'S OWN SLIDE — high exam priority
- Definitions as written on the slide:
  - TC: Total Cost = TC(Q)
  - MC: Marginal Cost = dTC(Q)/dQ
  - ATC: Total Average Cost = TC(Q) / Q (the slide's wording "Total Average Cost" means the same as average total cost [S19])
  - AVC: Average Variable Cost = VC(Q) / Q
- **(1) "When MC =ATC, the ATC becomes minimum."**
- **Proof (transcribed from the slide image):**

```
<Proof>  For ATC to be minimum,   dATC(Q)/dQ = 0.

dATC(Q)/dQ = d( TC(Q)/Q ) / dQ
           = [ dTC(Q)/dQ * Q − TC(Q) ] / Q²
           = [ MC(Q) * Q − TC(Q) ] / Q²
           = (1/Q) ( MC − TC(Q)/Q )
           = (1/Q) ( MC − ATC )

So,  dATC(Q)/dQ   > 0,  if MC > ATC,
                  = 0,  if MC = ATC,
                  < 0,  if MC < ATC
```

- Section 6.4 explains each step.

## 4. Key relationships

### 4.1 Marginal product vs total product [S5, S7, S8, S9]
- **MP > 0 → TP increasing. MP = 0 → TP does not change (the top of the TP curve). MP < 0 → TP decreases** [S7].
- MP is the slope of TP. This is shown by the tangent lines in [S7] and by Q′ = f′(L) in [S8].
- **Diminishing returns** means MP is decreasing (f″(L) < 0), so TP keeps rising but gets flatter. The [S5] caption says it "becomes flatter because the marginal product of labor declines".
- More fixed input (20 acres instead of 10) shifts TP and MPL **up**, but MPL still slopes down [S9].

### 4.2 From diminishing returns to rising costs [S12–S14, S18]
- Each worker costs the same $200 but adds fewer bushels. So TC rises by $200 for smaller and smaller increases in output, and the TC curve gets **steeper** [S13, S14].
- MC therefore rises. In the [S18] caption, the MC curve "slopes upward, reflecting diminishing returns to the variable input". At Ben's Boots, MC goes $12, $36 … $228, which is **increasing marginal cost** [S17].

### 4.3 MC vs ATC and AVC — the professor's 4 rules [S27, S28]
| Rule | Statement (slide wording) |
|---|---|
| (1) | When MC = ATC, the ATC becomes minimum. |
| (2) | When MC = AVC, the AVC becomes minimum. ("You can prove as (1).") |
| (3) | When MC is less than ATC, the ATC is decreasing. When MC is greater than ATC, the ATC is increasing. |
| (4) | When MC is less than AVC, the AVC is decreasing. When MC is greater than AVC, the AVC is increasing. |

- Intuition from the slide: "**For the average to be bigger, the new comer has to be greater than the average**" [S28].
- The same idea in the figures:
  - [S24]: MC crosses ATC at the bottom of the U, point M (3 pairs, $72).
  - [S25]: going from A₁ to A₂, MC (MC_L) is below ATC, so ATC falls. Going from B₁ to B₂, MC (MC_H) is above ATC, so ATC rises.
  - [S26]: even when MC first slopes down, "marginal cost that cuts through the minimum average total cost" still holds, and the graph shows MC crossing the bottom of AVC too.

### 4.4 Spreading effect vs diminishing returns effect → U-shaped ATC [S21, S23]
- **Spreading effect:** more output shares the fixed cost, so **AFC falls**.
- **Diminishing returns effect:** more output needs more variable input per extra unit, so **AVC rises**.
- At low output the spreading effect dominates and ATC falls. At high output the diminishing returns effect dominates and ATC rises. The result is a **U-shaped ATC** whose bottom is the **minimum-cost output**: 3 pairs at Ben's Boots [S21, S25]. See the [S23] table for the numbers.

### 4.5 Short run vs long run [S4, S29–S32]
- In the short run at least one input is fixed, so the firm has a fixed cost. In the long run all inputs can be varied, so the firm can choose its fixed cost [S4].
- There is a trade-off between **higher fixed cost and lower variable cost**. Low FC ($108) gives lower ATC at low output, and high FC ($216) gives lower ATC at high output [S29].
- LRATC shows ATC when fixed cost is chosen best for each output. Each short-run ATC touches LRATC at one output (A, C, X) and lies above it elsewhere (B, Y). In the short run the firm is stuck on its current short-run curve [S30].
- **Economies of scale** = LRATC falling; **diseconomies of scale** = LRATC rising; **constant returns to scale** = LRATC constant [S31].
- Table 7-3: FC and AFC are **short-run only**. VC, AVC, TC, ATC and MC apply in **both** the short run and the long run. LRATC is **long-run** [S32].

- At exactly 3 pairs, MC lies between $60 and $84. Their midpoint is (60 + 84)/2 = **$72 = ATC**. On Figure 7-8 the MC line passes exactly through M = (3, $72) [S24]. **So MC = ATC at the minimum-cost output**, which is rule (1).

**AVC at Ben's Boots:** the MC of the 1st pair ($12) equals AVC at 1 pair ($12). Every later MC is above the current AVC (36 > 12, 60 > 24, 84 > 36 …), so AVC rises the whole way (rule 4). AVC is therefore lowest at 1 pair, where MC = AVC (rule 2). This is why AVC on Figure 7-8 is a rising straight line.

### 6.4 Proof (1): ATC is at its minimum where MC = ATC [S27], step by step
1. **The goal.** The bottom of the U is where the slope of ATC is zero, which is why the slide writes "For ATC to be minimum, dATC(Q)/dQ = 0."
2. **Write ATC as a fraction.** ATC = TC(Q)/Q (definition on [S27], (7-4)).
3. **Differentiate the fraction.** The derivative of a fraction is (derivative of top × bottom − top × derivative of bottom) ÷ bottom². Here the top is TC(Q), whose derivative is dTC(Q)/dQ, and the bottom is Q, whose derivative is 1. That gives [dTC(Q)/dQ \* Q − TC(Q)] / Q². (🔎 Look up in Track B: "quotient rule" if you need a calculus refresher.)
4. **Use the definition of MC.** dTC(Q)/dQ = MC(Q), which gives [MC(Q) \* Q − TC(Q)] / Q².
5. **Split the fraction.** [MC·Q − TC]/Q² = (1/Q)·(MC − TC(Q)/Q).
6. **Use the definition of ATC.** TC(Q)/Q = ATC, so **dATC/dQ = (1/Q)(MC − ATC)**.
7. **Read off the sign.** Q > 0, so 1/Q > 0, and the slope of ATC has the same sign as (MC − ATC):
   - MC > ATC → slope > 0, so ATC is rising.
   - MC = ATC → slope = 0, so this is the bottom.
   - MC < ATC → slope < 0, so ATC is falling.
8. **Conclusion.** On the slides' graphs ([S24], [S25]) MC is below ATC to the left of M (ATC falling) and above it to the right (ATC rising). The point where MC = ATC is therefore the **minimum** of ATC. Step 7 is also rule (3), which is why [S28] says "From the proof of (1)".

### 6.5 Proof (2): AVC is at its minimum where MC = AVC ("You can prove as (1)" [S28])
Same steps, with VC in place of TC:

```
dAVC(Q)/dQ = d( VC(Q)/Q ) / dQ
           = [ dVC(Q)/dQ * Q − VC(Q) ] / Q²
           = (1/Q) ( dVC(Q)/dQ − VC(Q)/Q )
           = (1/Q) ( MC − AVC )
```
- The one extra fact used: TC = FC + VC, and FC "does not depend on the quantity of output produced" [S11]. So the change in TC equals the change in VC, i.e. dVC/dQ = dTC/dQ = MC. Table 7-1 shows this with numbers (156 − 120 = 48 − 12 = 36).
- So dAVC/dQ = 0 exactly when MC = AVC, which is the minimum of AVC. MC < AVC → AVC falling; MC > AVC → AVC rising. That is rule (4).

### 6.6 The professor's "average" example [S28]
- The slide lists numbers "165, 170, 172, 181, 178, 175, 182, 166, ………" with "**average = 175**". They look like students' heights in cm, but the slide does not label them.
- The key sentence: "**For the average to be bigger, the new comer has to be greater than the average.**"
- **Illustration (my arithmetic on the slide's example).** Suppose, just for the numbers, that 8 people average 175, so their total is 8 × 175 = 1,400.
  - Newcomer **184** (> 175): (1,400 + 184)/9 = 1,584/9 = **176**, so the average **rises**.
  - Newcomer **166** (< 175): (1,400 + 166)/9 = 1,566/9 = **174**, so the average **falls**.
  - Newcomer **175** (= 175): 1,575/9 = **175**, so the average is **unchanged**.
- **Link to costs.** MC is the "newcomer" (the cost of one more unit) and ATC is the "average".
  - MC > ATC → ATC rises.
  - MC < ATC → ATC falls.
  - MC = ATC → ATC stays the same, which is the flat bottom of the U.
  - "The same relation applies to MC and AVC" [S28].
- **Ben's Boots in the same language.** The average for 2 pairs is $78. The newcomer (3rd pair) costs $60, which is less than 78, so the average falls to $72. The next newcomer (4th pair) costs $84, which is more than 72, so the average rises to $75.
