## Page 4

What Is a Socket?
10/4/2026
SOC 3010              j.yusupov@inha.uz
Sockets
Four names, all new today
Socket — one end of a conversation between two processes.
The OS creates it and gives it to you as a file descriptor (the “ticket number” of Weekௗ3).
Connection — two sockets joined together: a two-way stream of bytes.
Server — the process that waits to be called.
Client — the process that calls.
Think of a telephone
socket = the phone on your desk
connection = the call · server = a shop waiting by its phone
client = the customer who dials.
Both sides can talk and listen on the same call — a pipe could only do one direction.
