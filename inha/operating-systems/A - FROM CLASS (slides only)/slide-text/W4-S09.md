A counter that processes can decrease and increase atomically, and that makes a
process sleep when there is nothing left to take. That counter is the semaphore.

How to read the drawing
The value = the number of flags in the “hole”. wait takes

The Counter, With a Semaphore
9/29/2026
SOC 3010              j.yusupov@inha.uz
Semaphores
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/wait.h>
#include <semaphore.h>
#include "shared_mem.h"
#define N 1000000
struct shared {
    sem_t lock;  /* the padlock ...            */
    long  counter; /* ... and what it protects   */
};
int main(void) {
    struct shared *s = shared_alloc(sizeof(struct shared));
    s->counter = 0;
    sem_init(&s->lock, 1, 1); /* 1: shared by processes, 1: open */
    pid_t pid = fork();
    for (int i = 0; i < N; i++) {
        sem_wait(&s->lock); /* take the key, or sleep         */
        s->counter++;   /* critical section               */
        sem_post(&s->lock); /* give the key back              */
    }
    if (pid == 0) exit(0);
    wait(NULL);
    printf("expected %d, got %ld\n", 2 * N, s->counter);
    sem_destroy(&s->lock);
    return 0;
}
gcc -o sem sem.c -pthread
You need the -pthread flag because
POSIX semaphores are part of the
POSIX Threads library (libpthread)
