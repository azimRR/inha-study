What is a subshell?
9/13/2026
SOC 3010              j.yusupov@inha.uz
The Shell
A subshell is a child copy of the current shell process. It inherits everything
(variables, functions, options) but any changes it makes are invisible to the parent.
# Parentheses create a subshell
( x=42; echo "inside: $x" )
echo "outside: $x"   # x is unset here
# Braces group in the CURRENT shell
{ x=42; echo "inside: $x"; }
echo "outside: $x"   # x is 42 here

Bash Script Programming: Putting it all together
Programming or Scripting ?
•
Programming languages are generally a lot more
powerful and a lot faster than scripting
languages. Programming languages generally start
from source code and are compiled into an
executable. This executable is not easily ported into
different operating systems.
•
A scripting language also starts from source code,
but is not compiled into an executable. Rather, an
interpreter reads the instructions in the source file
and executes each instruction. Interpreted programs
are generally slower than compiled programs. The
main advantage is that you can easily port the source
file to any operating system. bash is a scripting
language. Other examples of scripting languages are
Perl, Lisp, and Tcl.
