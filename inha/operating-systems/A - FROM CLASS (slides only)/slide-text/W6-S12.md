What Is Synchronisation?
10/11/26
SOC 3010              j.yusupov@inha.uz
Synchronisation I: Patterns
Week 4 gave you one counter with two operations. This week the same counter learns five jobs — enough to run a whole café.
Synchronisation is the set of rules that decide who may
do what, and when, when several processes share
something. With them, the result of the program no longer
depends on the order the scheduler happens to choose.
The OS supplies the mechanism: an atomic counter, sleep, wake
exactly one. You supply the pattern — which process waits, which
posts, and in what order. The pattern is this week's subject.
Synchronisation = make the answer independent of the interleaving.
What the OS gives, what you give
